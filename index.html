Brutalist UI

Library komponen Neo-Brutalism yang ringan, tanpa dependencies, dan mendukung dark mode dinamis. Copy-paste, langsung pakai.

01 — Warna & Token

Semua warna diambil dari CSS variables. Ubah satu variabel, ubah seluruh tema.

Primary
Secondary
Success
Info
Danger
:root {
  --br-primary:   #4ECDC4;
  --br-secondary: #FFD93D;
  --br-success:   #95E1A3;
  --br-info:      #A8D8FF;
  --br-danger:    #FF6B6B;
}

08 — Accordion

Bisa single open (pakai data-br-accordion-group) atau multiple.

Apa itu Neo-Brutalism? +
Neo-Brutalism adalah gaya desain yang menonjolkan border tebal, warna kontras, dan hard shadow tanpa blur.
Apakah library ini gratis? +
Ya, bebas dipakai untuk proyek pribadi maupun komersial.
Butuh dependencies? +
Tidak. Hanya HTML, CSS, dan Vanilla JS. Tanpa framework. 
<div data-br-accordion-group>
  <div class="br-accordion is-open">
    <div class="br-accordion__header">
      Judul <span class="br-accordion__icon">+</span>
    </div>
    <div class="br-accordion__body">Isi...</div>
  </div>
</div>
